MCP configuration ↗
Clear scope. Reviewable code.

A guardrail,
with visible boundaries.

Static checks cannot prove a repository is safe. Dynamic environment reads, encoded credentials, and remote workflow bodies need other review. Test fixtures and templates are excluded from secret scanning by default.

Read the detection limits ↗
  • No repository scripts are executed during scanning.
  • Source code stays on the machine running the audit.
  • Findings never contain detected secret values.
  • Ignore policy and official-action allowlists are configurable.
  • Excess-size files produce explicit warnings.
  • Deterministic JSON and SARIF 2.1.0 output for CI pipelines.
